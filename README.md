# TaliaMadeIt

Private chef website for TaliaMadeIt — a health-forward, fine-dining private chef experience based in New York City.

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, CSS Grid, Flexbox, animations
- **Vanilla JavaScript** — No frameworks or dependencies
- **Google Fonts** — Cormorant Garamond, Great Vibes, Jost

## Project Structure

```
taliamadeit/
├── index.html          # Single-page site
├── css/
│   ├── variables.css   # Design tokens
│   ├── base.css        # Reset, typography, utilities
│   ├── animations.css  # Keyframes
│   ├── nav.css         # Fixed navigation
│   ├── hero.css        # Hero section
│   ├── sections.css    # About, Services, Testimonial, CTA
│   ├── menus.css       # Tabbed menu section
│   ├── gallery.css     # Image gallery grid
│   ├── contact.css     # Contact form
│   └── footer.css      # Footer
├── js/
│   ├── nav.js          # Scroll behavior + mobile menu
│   ├── reveal.js       # Scroll reveal animations
│   ├── menus.js        # Menu tab switching
│   └── form.js         # Contact form handling
├── assets/
│   └── images/         # Local images (currently using Unsplash)
└── README.md
```

## Sections

1. Fixed navigation with scroll transition
2. Full-viewport hero with animated entrance

4. Philosophy quote section
5. About the chef
6. Services grid
7. Testimonial

## Running Locally

Open `index.html` in any modern browser. No build step required.
